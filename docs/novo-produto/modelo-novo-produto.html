Formato principal O formato só define o ponto de partida (capa, nome dos itens e o primeiro tipo sugerido). Dentro do produto, qualquer item pode ser vídeo, áudio ou PDF, e qualquer item pode ter materiais extras dos três tipos. Dá para trocar o formato depois.

Categoria A categoria define em qual vitrine o produto aparece para os alunos. Dá para mudar depois e colocar o produto em mais de uma categoria.
